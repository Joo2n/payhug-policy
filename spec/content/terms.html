1. 기본 용어

선정산

플랫폼 또는 카드사로부터 실제 정산금이 입금되기 전에 PayHug가 가맹점에 먼저 지급하는 금액.

승인 매출

카드 또는 배달 플랫폼에서 결제가 승인된 매출.

매입 매출

승인된 거래 중 카드사 또는 플랫폼 정산 대상으로 확정된 매출.

반영 매출액

현재 선정산 계산에 포함된 매출의 합계.

선정산 반영 금액

전체 매출 중 실제 선정산 계산에 포함된 금액.

예상 지급액

아직 최종 확정되지 않은 데이터를 기준으로 계산한 지급 예정 금액.

확정 지급액

수수료·환급·차감·제외·회수 등을 모두 반영한 최종 지급 금액.

예상 지급 차액

정확한 정의는 미확정.

후보:

  • 최초 예상 지급액과 최종 지급액의 차이
  • 당사 계산액과 플랫폼 최종 입금액의 차이
  • 추가 지급 또는 회수 예정 금액
  • 대사 불일치 금액

정규 매니저와 정의 확정 필요.

2. 지급 관련 용어

미지급금

원래 가맹점에게 지급해야 했으나 실제 지급되지 않은 금액.

예:

  • 플랫폼 환급 누락
  • 지급 배치 누락
  • 계좌 오류
  • 바로이체 실패
  • 데이터 지연으로 인한 지급 누락

선정산 제외금액

정책상 이번 선정산 지급 대상에서 제외한 금액.

예:

  • 매입 미확정
  • 검증 불가
  • 위험 거래
  • 지급 보류
  • 한도 초과
  • 계약상 제외

미지급금과 선정산 제외금액은 구분해야 한다.

바로이체 대상금액

정규 선정산 지급과 별도로 지급해야 하는 금액으로 추정된다.

정확한 생성 조건은 확인 필요.

바로이체 미지급

바로이체 대상으로 생성되었으나 아직 실제 지급되지 않은 금액 또는 상태로 추정된다.

3. 환급 관련 용어

플랫폼 환급

플랫폼이 가맹점에게 돌려주도록 정산 상세에 반영한 금액.

금액 방향:

  • 원칙적으로 +
  • 가맹점에게 추가 지급

자체환급분

현재 운영에서 사용하는 표현.

당사가 자체 보상하는 금액이라기보다, 플랫폼이 자체적으로 생성한 환급 항목을 의미하는 것으로 파악됨.

가맹점 노출 용어는 플랫폼 환급금 권장.

4. 회수 관련 용어

과지급

PayHug가 가맹점에게 실제 지급해야 할 금액보다 더 지급한 발생 금액.

미회수금

과지급 또는 기타 회수 사유가 발생한 뒤 아직 회수되지 않은 잔액.

권장 구분:

  • 과지급: 발생 원인과 최초 금액
  • 미회수금: 현재 남아 있는 회수 잔액

회수

가맹점에게 초과 지급된 금액을 다시 확보하는 처리.

가능 방식:

  • 다음 선정산액에서 차감
  • 락계좌에서 회수
  • 가맹점 직접 입금
  • 운영자 수동 처리
  • 부분 회수
  • 분할 회수

상계

가맹점에게 새로 지급할 금액과 회수할 금액을 서로 차감하여 정산하는 방식.
